# Force-Directed Graph Layout as Unconstrained Optimization

Mini project for the Optimization course (Module 2: gradient-based multivariable
optimization).

Draw a graph by treating nodes as charged particles (they repel) and edges as
springs (they pull). The "nicest" 2D layout is the minimiser of a total energy
`E(x_1, y_1, ..., x_n, y_n)`. We minimise it with four methods from the syllabus
and compare them.
